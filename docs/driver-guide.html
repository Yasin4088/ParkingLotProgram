1 登录与注册

1.1 首次登录

打开小程序后，默认显示「司机」登录页。司机使用微信一键登录，无需输入账号密码。

点击「微信一键登录」
系统通过微信授权自动登录，登录后进入注册信息完善页面。
获取手机号
点击「微信授权获取手机号」按钮，一键获取本机微信绑定的手机号。也可以手动输入手机号（仅开发测试用）。
填写基本信息
填写真实姓名、身份证号（18位）、车牌号（如粤B12345）。
上传证件照片（三证齐全）
依次上传驾驶证照片、行驶证照片、身份证照片。可拍照或从相册选择，点击已上传的照片可重新上传。
提交注册
确认信息无误后点击「提交注册」，完成后自动进入业务选择页。
提示：所有信息仅用于停车场管理，不会外泄。车牌号和手机号会在后续操作中自动预填，可随时修改。

1.2 日常登录

注册完成后，每次打开小程序点击「微信一键登录」即可直接进入业务选择页，无需重复填写信息。

2 功能总览

登录后进入业务选择页，提供三大功能模块：

🚚
装卸货
认领任务 → GPS签到排队 → 叫号 → 叉车装卸 → 结算支付
📦
存柜
登记存柜 → 生成存柜码 → 叫号 → 吊柜存柜作业
🔓
取柜
输入存柜码 → 查询费用 → 缴费 → 叫号 → 吊柜取柜作业
进行中提示：如果有正在进行的装卸货任务，装卸货卡片上会显示「进行中」角标，方便您快速回到排队页面。

页面底部提供两个入口：个人信息修改（查看和修改注册信息）和退出登录。

3 装卸货操作流程

3.1 整体流程

待认领 → 已预约 → 排队中 → 已叫号 → 执行中 → 待结算 → 待支付 → 已完成

3.2 认领任务

管理员会提前在系统中创建任务（包含车牌号和备注信息）。您需要在「认领任务」页面输入与任务一致的车牌号来认领。

进入装卸货页面
在业务选择页点击「装卸货」进入认领任务页。车牌号和手机号会自动预填注册时的信息，可修改。
输入车牌号
车牌号需与管理员创建任务时填写的完全一致（如粤B12345），否则无法认领。
输入手机号
用于现场联系，请确保手机号正确。
上传单证照片（可选）
可拍照或从相册上传单据照片，方便管理员核对。非必填。
点击「认领任务」
认领成功后自动跳转到「我的排队」页面。
注意：一个车牌号同一时间只能有一个进行中的任务。如果提示认领失败，请确认车牌号是否正确或是否已有进行中的任务。

3.3 GPS签到排队

认领任务后状态为「已预约」，需要到达停车场堆场后完成GPS签到才能进入排队队列。

到达停车场
驾车到达指定停车场装卸堆场。
点击「GPS签到」
在「我的排队」页面点击按钮，系统自动获取您的位置信息完成签到。签到后状态变为「排队中」，系统分配排队号。
定位失败怎么办？如果提示「定位失败」，请检查：① 手机GPS定位是否开启；② 小程序是否已授权获取位置信息（可在微信设置中检查）；③ 是否已到达停车场附近。

3.4 等待叫号

签到后进入排队队列，页面显示您的排队号和前方人数。管理员叫到您时，状态变为「已叫号」。

  • 订阅通知：在排队中可点击「订阅叫号通知」，叫号时收到微信消息提醒（需授权订阅消息）。
  • 确认收到：被叫号后，页面显示「已叫号，请确认收到通知」，点击「确认收到」按钮确认，叉车司机收到通知后前往装卸。

3.5 装卸执行与结算

状态 含义 您需要做什么
执行中 叉车司机正在装卸作业 留意现场安排，配合装卸
待结算 装卸完成，管理员核对费用 等待管理员结算，可在页面查看费用明细
待支付 费用已锁定，等待支付 按页面提示完成支付后离场
已完成 全部流程结束 可离场，历史记录保留可查
费用说明：费用项目包括办单费、过磅费、拆箱费、吊机费、存柜费等固定项及自定义项，由管理员录入。支付前管理员可随时修改费用。金额单位为元，页面直接显示。

3.6 支付

状态变为「待支付」后，页面显示费用合计金额和「去支付」按钮。支付方式分为两种：

  • 现场支付：在线支付未开通时，请到现场向管理员缴费，管理员确认收款后订单完成。
  • 在线支付（开通后）：点击「去支付」拉起微信支付，完成支付后自动完成订单。
  • 客户记账：管理员在建单时可预填为记账模式，结算后直接完成，无需现场支付。
支付状态说明：未支付=待付款；已支付=已在线支付完成；免支付=管理员设为免支付；记账=客户月结。

4 存柜操作流程

4.1 整体流程

待叫号·存柜 → 已叫号·存柜 → 存柜执行中 → 已存柜

4.2 存柜登记

在业务选择页点击「存柜」进入存柜登记页面。存柜登记免费，登记后系统自动生成存柜码和排队号。

填写车牌号和手机号
自动预填注册信息，可修改。手机号用于现场联系。
选择柜型
从下拉列表选择柜型，不同柜型对应不同的日单价（页面显示价格）。
输入柜号
填写柜号，如 A-101。
选择所属公司
挚力：正常计费，取柜时按天收费，支持月付识别。
其他：不计费不付款，取柜时直接排队，不留历史记录。如需月付识别请选「挚力」。
上传柜门照片（必传）
拍照或从相册上传柜门照片，此为必填项。
点击「登记存柜」
提交后弹出存柜码（6位数字）和排队号。可点击「复制存柜码」保存到剪贴板。页面自动跳转到「我的存取柜」。
请妥善保存存柜码！存柜码是取柜时的重要凭证，取柜时需要输入此码查询费用并登记。建议截图保存或复制到备忘录。

4.3 存柜状态说明

状态 含义
待叫号 已登记，等待管理员叫号后吊柜司机开始存柜
已叫号 管理员已叫号，等待吊柜司机接单
存柜执行中 吊柜司机正在存柜作业，请留意现场安排
已存柜 存柜完成，取柜时凭存柜码登记并按天缴费

5 取柜操作流程

5.1 整体流程

取柜待缴费 → 取柜待叫号 → 已叫号·取柜 → 取柜执行中 → 已取柜

5.2 取柜登记与缴费

在业务选择页点击「取柜」进入取柜登记页面。取柜按天计费，不足1天按1天计算。

输入存柜码
输入存柜时获得的6位数字存柜码。
输入手机号
用于现场联系。
填写取柜车牌
默认预填注册车牌号，可修改。如果是月付司机，填写月付车牌后系统自动识别，免现场缴费（费用记公司月结）。
点击「查询费用」
系统显示柜型、柜号、车牌、存柜时间、计费天数和合计费用。
提交取柜登记
根据费用情况不同，提交后流程不同（见下方说明）。

5.3 三种取柜情况

情况 页面提示 后续流程
正常计费 显示天数×日单价=合计费用，按钮显示「支付费用」 在线支付开通时：提交后自动拉起微信支付，支付完成进入取柜排队；未开通时：提交后请现场缴费，管理员确认收款后进入排队
月付车牌识别 显示「已识别到月付车牌，本单免现场缴费」 提交后直接进入取柜排队，无需现场缴费（费用记公司月结）
其他公司单 显示「其他公司单，不计费」 提交后直接进入取柜排队，无需付款
计费规则：计费起点为存柜完成时间（吊柜拍照确认时），按天计费，不足1天按1天。费用 = 天数 × 柜型日单价。费用在取柜登记时由服务端锁定。

5.4 取柜状态说明

状态 含义
取柜待缴费 费用已锁定，请完成支付（或现场缴费后等待管理员确认收款）
取柜待叫号 已缴费（或免付/月付），等待管理员叫号
已叫号·取柜 管理员已叫号，等待吊柜司机接单
取柜执行中 吊柜司机正在取柜作业，请留意现场安排
已取柜 取柜完成，全部流程结束

6 我的存取柜（进度查看与支付）

在存柜页面底部点击「查看我的存柜」或在取柜页面点击「查看我的取柜」，可进入「我的存取柜」页面，查看所有进行中的存取柜记录。

6.1 页面功能

  • 存柜码展示：每条记录显示存柜码，可点击复制。
  • 状态与排队进度：显示当前状态、排队号、前方人数。
  • 费用明细：取柜阶段（状态≥4）显示计费天数、日单价、合计费用和支付状态。
  • 状态提示：根据当前状态显示操作提示（如「请完成支付」「等待管理员叫号」等）。
  • 去支付按钮：在线支付开通且状态为「取柜待缴费」时，显示「去支付 ¥xx」按钮。

6.2 底部快捷入口

  • 我要存柜：快速跳转到存柜登记页。
  • 我要取柜：快速跳转到取柜登记页。
  • 刷新：手动刷新页面数据，获取最新状态。
记录展示规则：进行中的存取柜记录会一直显示在页面上，取出完成后记录消失。如果没有进行中的记录，会显示最近一条历史记录供参考。

7 个人信息管理

在业务选择页底部点击「个人信息修改」，可查看和修改您的注册信息。

  • 可修改手机号、姓名、身份证号、车牌号
  • 可重新上传驾驶证、行驶证、身份证照片
  • 修改后点击「保存修改」即可生效
注意：车牌号是认领任务和存取柜登记的重要信息，修改后请确保与实际车辆一致。

8 常见问题

认领任务时提示失败怎么办？
请确认：① 车牌号与管理员创建任务时的车牌号完全一致（包括大小写）；② 当前没有其他进行中的任务（同一车牌同时只能有一个进行中的任务）；③ 管理员已创建任务。如仍无法解决，请联系管理员核实。
GPS签到定位失败怎么办？
请检查：① 手机GPS定位功能是否开启；② 微信是否已授权小程序获取位置信息（微信→我→设置→个人信息与权限→授权管理）；③ 是否已到达停车场附近。如问题持续，可尝试退出小程序重新进入或重启手机定位。
存柜码忘记了怎么办？
在「我的存取柜」页面可以查看所有进行中的存柜记录，每条记录都会显示存柜码，可点击复制。建议登记成功后立即截图保存。
取柜费用是怎么算的？
费用 = 存柜天数 × 柜型日单价。计费起点为存柜完成时间（吊柜司机拍照确认时），按天计费，不足1天按1天计算。费用在取柜登记时由系统自动锁定。
月付司机怎么免现场缴费？
月付客户会在系统中录入月付司机车牌。取柜登记时在「取柜车牌」栏填写与月付池匹配的车牌号，系统自动识别后显示「已识别到月付车牌，本单免现场缴费」，提交后直接进入取柜排队，费用记公司月结。
支付功能什么时候开通？
在线支付功能开通前，请到现场向管理员缴费，管理员确认收款后订单自动完成。在线支付开通后，点击「去支付」可直接拉起微信支付完成付款。
怎么收到叫号通知？
在排队页面点击「订阅叫号通知」按钮，授权后当管理员叫到您的号时会收到微信消息提醒。每次订阅仅对当前任务有效，新任务需重新订阅。
退出登录后数据还在吗？
退出登录不影响已提交的任务和存取柜记录。重新使用微信一键登录后，可以继续查看进行中的任务和历史记录。
「其他公司」是什么意思？
存柜登记时选择「其他公司」的存柜单不计费不付款，取柜时直接排队，且不留历史记录。如果您需要正常计费或月付识别，请选择「挚力」。
